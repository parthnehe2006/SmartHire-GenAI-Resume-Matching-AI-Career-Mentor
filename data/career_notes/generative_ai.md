# Generative AI Career Guide

## Role Overview

Generative AI focuses on systems that can generate text, code, images, and other forms of content using generative models.

## Core Skills

Important skills include:

- Python
- Machine Learning
- Deep Learning
- Large Language Models
- Prompt Engineering
- Embeddings
- Vector Databases
- RAG
- LangChain
- APIs
- Git
- GitHub

## Common Responsibilities

A Generative AI developer may:

- Build applications using LLM APIs
- Design prompts
- Create RAG systems
- Generate and store embeddings
- Work with vector databases
- Build AI-powered applications
- Evaluate model responses
- Implement safety and guardrails

## Useful Learning Path

1. Learn Python.
2. Understand machine learning fundamentals.
3. Learn neural networks and deep learning.
4. Understand large language models.
5. Learn prompt engineering.
6. Learn embeddings.
7. Learn vector databases.
8. Learn Retrieval-Augmented Generation.
9. Build LLM applications.
10. Learn evaluation and responsible AI.

## Portfolio Projects

Useful projects include:

- AI resume analyzer
- RAG chatbot
- Document question-answering system
- AI career assistant
- Resume improvement generator
- Semantic search application

## Career Advice

Students should build practical applications that demonstrate their understanding of LLM APIs, embeddings, retrieval, RAG, prompt engineering, evaluation, and responsible AI.
