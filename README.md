# SmartHire-GenAI-Resume-Matching-AI-Career-Mentor
SmartHire-GenAI is a Generative AI-powered career assistance platform that extracts structured information from resumes, matches candidates with relevant jobs using embeddings and FAISS, provides AI-generated resume improvement suggestions, and offers a Retrieval-Augmented Generation (RAG) based career mentor chatbot built with LangChain.
